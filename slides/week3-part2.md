# 先看主页，再看约定作品

```mermaid
flowchart LR
  A[主页首印象] --> B[阅读约定作品]
  B --> C[保存原话与动作]
  C --> D[活动后听作者解释]
```

- 主页约半分钟：主要有什么内容？从哪里看出？
- 作品给足阅读时间；只看片段，就注明范围。

<div class="takeaway">先留下解释前的记录，再开始对照。</div>

<!--
半分钟是课堂组织安排，不是注意力阈值。作者只帮助打开页面，不带对方寻找预设答案。作品超过本轮时间时，共同限定片段并写“未完整浏览”。若同伴停住，问“你现在看到了什么？”而不是代答；解释统一放到20分钟活动结束后。来源：讲义150—154行、教案169—173行。

# 问位置，不把原因塞进问题

<div class="pair">
<div>
<div class="label">避免诱导</div>
<p>“是不是封面不够吸引人？”</p>
<p>问题已经替对方选好了原因。</p>
</div>
<div>
<div class="label">改为中性追问</div>
<p>“你刚才先看了哪里？”</p>
<p>请对方指出具体句子或画面。</p>
</div>
</div>

<div class="takeaway">不用凑三个缺点；没有明显障碍也可以如实记录。</div>

<!--
示范语气保持平稳，不在问句后补“我觉得这里不清楚”。可继续问“哪一处让你不明白？”“如果需要用到信息，你还会核实什么？”学生只说好或不好时，请其指出位置；仍无问题就记录未遇明显障碍，不硬凑缺点。来源：讲义156—158行、教案175—184行。
建议用时：1分钟

# 把说出的、看见的、想到的分开

<div class="pair">
<div>
<div class="label">先保留现场事实</div>
<p>原话：对方实际说了什么。</p>
<p>观察：记录者看见了什么动作。</p>
</div>
<div>
<div class="label">再写解释</div>
<p>作者意图：原本希望表达什么。</p>
<p>记录者推测：为什么可能如此。</p>
</div>
</div>

<div class="takeaway">解释另栏保存，不能冒充原话或可见行为。</div>

<!--
活动结束，先交换记录，请反馈者确认有没有误记。再让作者补充意图。问全班“停留很久”与“没有兴趣”分别属于什么：前者仍须有实际观察，后者是推测。没有可见行为可以留空，不从表情猜心理。后续用同一教学虚构案例练习分栏。来源：讲义160—171行、教案186行。

# 对照理解差异，不给同伴打分

<div class="practice-box">在自己的记录旁标出：一致、不同、尚不清楚。</div>

- 用原话和作品位置说明你为何这样标。
- 作者解释后新增的理解，另记为讨论后反馈。
- 没有证据就保留未知，不强行判对或判错。

<div class="takeaway">保留差异，不计算“理解一致率”或“偏差率”。</div>

<!--
用两分钟让每人核对一条记录，并与同伴确认。可问“哪句话支持你说一致？”“不同的是内容主题还是下一步操作？”学生卡住时回到具体句子，不要求立即给出运营建议。如果双方仍说不清，就标尚不清楚并写待核问题。此时不把同伴当目标用户，不用百分比制造精度。来源：教案166—167行，讲义173—186行。

# 带着一个待验证问题交给Agent

<div class="lead">先圈出：一条事实、一条解释、一个未知。</div>

- 同伴检查：有没有把解释或未知写成事实？
- 文件齐备：账号说明、作品样本、现场反馈。
- 下节任务：让Agent依据材料起草诊断，再由人核查。

<div class="takeaway">AI可以整理记录，不能编造“真实用户评价”。</div>
