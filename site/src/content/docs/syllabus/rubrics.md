## 可署名责任与过程性考核核心理念

本课程杜绝“期末凭一份 PPT 突击拿分”的传统模式，推行工业级的**可署名责任制（Signable Accountability）**与**阶段过程性量规（Rubrics）**：

- **一人一档，留痕可追溯**：每个团队成员的分工必须在项目 README 与任务工单中具名锁定，严禁搭便车。
- **证据链闭环**：所有提交物必须附带原始信源依据、同伴走查原话或数据监测日志，查无实据的一律打回。
- **人机权责分明**：AI Agent 仅承担辅助推演、特征聚类与格式排版，最终选题、事实真伪、价值导向与发布决策必须由学生签署真实姓名承担法律与道德责任。

## 阶段实践作业考核量规矩阵

### 实践一：需求调研与选题策划案 (10分)

| 评价维度（权重） | 卓越 (9-10分) | 良好 (7-8分) | 待改进 (6分) | 不合格 (0-5分) |
| :--- | :--- | :--- | :--- | :--- |
| **多源需求互证 (40%)** | 结合主动搜索、长篇问答、差评客诉提供 3 种独立证据，彻底破除评论区发声者偏差 | 具备 2 类独立证据，分析基本扎实 | 仅依赖单一社媒评论区留言，存在幸存者偏差 | 无真实数据支撑，纯属凭空臆想 |
| **竞品逆向拆解 (30%)** | 黄金 Hook、中段留存与尾部 CTA 拆解透彻，找到明确认知破局点 | 竞品分析框架完整，对比逻辑通顺 | 仅列举表面数据，缺乏叙事力学拆解 | 简单截图堆砌，无有效分析 |
| **选题可行性与伦理 (30%)** | 通过全部杀手清单筛查，无版权伦理隐患，具备可操作采访信源 | 伦理审查清晰，采访路径基本可行 | 选题过于宽泛或存在潜在版权争议 | 选题涉及违规红线或严重脱离实际 |

### 实践二：可执行内容简报与原型工程 (10分)

| 评价维度（权重） | 卓越 (9-10分) | 良好 (7-8分) | 待改进 (6分) | 不合格 (0-5分) |
| :--- | :--- | :--- | :--- | :--- |
| **JTBD 受众雇佣诊断 (30%)** | 精准切中受众现实困境，功能型与情绪型工作定义深刻具象 | 雇佣场景明确，痛点描述相对清晰 | 痛点描述模糊，有一定自嗨倾向 | 完全脱离受众真实需求 |
| **媒介形态科学匹配 (30%)** | 依据信息密度、情绪张力严密论证选型，图文/视频载体匹配极佳 | 选型合理，包含主要理论论证 | 选型随大流，未充分结合题材特征 | 形式与内容严重脱节 |
| **黄金开头 Hook 动力学 (40%)** | 3 组变体风格迥异，话题+抓手+可信度完备，盲测全票通过 | 三要素齐全，口播通顺无卡壳 | 要素有缺失，书面语较重，存在朗读卡壳 | 充斥自问自答与无效客套废话 |

### 实践三：多模态内容初稿与中期开发汇报 (10分)

| 评价维度（权重） | 卓越 (9-10分) | 良好 (7-8分) | 待改进 (6分) | 不合格 (0-5分) |
| :--- | :--- | :--- | :--- | :--- |
| **视听脚本与分镜质量 (40%)** | 镜头景别、画面动作、台词音效与视听心理学精准配合 | 分镜要素齐全，音画配合顺畅 | 分镜粗略，视听节奏缺乏设计 | 仅提供文字大纲，无分镜脚本 |
| **人机协同流水线规范 (30%)** | 完整展示 Skill 调度、知识库引用与人工修改留痕记录 | 具备基本 Skill 运行和改稿痕迹 | 人工介入不足，有大模型直接代写痕迹 | 纯手工拼凑或完全失控的模型生成 |
| **中期复盘与纠偏能力 (30%)** | 能够诚实面对生产卡点，给出科学可行的纠偏方案 | 发现主要问题并提出改进措施 | 避重就轻，回避关键质量缺陷 | 无复盘意识，拒绝调整方案 |

## 期末大作业考核量规 (30分)

| 核心维度（分值） | 卓越标准 | 良好标准 | 及格标准 |
| :--- | :--- | :--- | :--- |
| **产品完整度与公开发布 (10分)** | 作品已在目标主流平台正式发布上线，格式规范，排版精美，链接可公开访问。 | 作品已发布，排版与交互体验基本达到媒体要求。 | 作品已完成但未完成公开发布，或存在局部格式瑕疵。 |
| **数据表现与真实反馈 (10分)** | 拥有完整的发布观察窗口数据，完成受众真实互动归因与留存复盘。 | 具备基础播放量、阅读量统计与简单复盘。 | 仅展示零星后台截图，缺乏数据归因与思考。 |
| **项目工作集与工作流交付 (10分)** | 交付包含全套 Skill、LLM-Wiki 知识库、审核日志与代表作品集的高质量工程归档包。 | 交付了完整的期末报告、脚本文件与演示 PPT。 | 材料不齐全，文档格式杂乱，缺乏版本追踪。 |
