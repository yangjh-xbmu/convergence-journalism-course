## 课程顶层定位：双螺旋协同框架

本课程与专业骨干课《新媒体运营》（32 学时）确立“**产品研发—运营增长**”双螺旋协同框架：

- **《融合新闻产品策划与制作》（本课程）定位为“内容研发中台与技术兵工厂”**：
  聚焦于融媒体内容的产品化思维、工业化生产流水线（AI Agent 赋能）、多模态视听高质量制作、数据监控看板搭建与 A/B 迭代实验，解决“如何高质高人效生产内容、如何基于数据进行科学归因”的根本问题。
- **《新媒体运营》（协同主场）定位为“前台分发渠道与用户运营主战场”**：
  聚焦于平台生态文化、社区互动机制、公域到私域承接、平台合规把关及长周期账号指标验收（2 个月、20+ 条作品、500 净增粉丝、5 万播放/3 万阅读），解决“内容往哪分发、流量如何增长、用户如何留存”的根本问题。

两门课程共享一套真实账号资产，彻底杜绝两个账号重复造轮子、疲于刷量的沉重学业负担。

## 考核及成绩评定方式

本课程采用全程过程性考核与终结性考核相结合的方式，总分 100 分：

1. **课堂表现（20分）**：考查出勤率、课堂出声走查参与度、同伴盲测打分互动。
2. **课后作业（20分）**：个人撰写《AI 工具对新闻生产的影响分析报告》与个人 Skill 沉淀。
3. **阶段综合实践（30分）**：
   - 实践一：账号情报监测与选题候选清单（10分）
   - 实践二：可执行内容简报与信源审核表（10分）
   - 实践三：多模态内容初稿与中期开发汇报（10分）
4. **期末终结性大作业（30分）**：团队完成一套信息服务型融媒体产品正式发布与综合作品集汇报。
