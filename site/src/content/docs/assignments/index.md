## 作业设计体系与理念

本课程作业面向新闻传播学大三学生设计，核心目标是让每位同学在结课时沉淀出可用于**实习应聘、个人作品集与毕业求职**的高质量实战资产。

小组项目围绕同一件真实需求驱动的“**信息服务型融媒体产品**”连续演进，形成从需求调研、原型设计、视听开发到正式发布的完整闭环。

## 提交规范与注意事项

1. **学习通通知纯文本同步**：
   作业通知已在学习通同步发布。提交时，组长在学习通提交最终排版后的 PDF/DOCX 文件，并在文本框按规范填写分工。
2. **Git 版本库留痕**：
   过程性脚本、Skill 代码、Markdown 简报与数据表格，建议同步推送到组长或成员的 GitHub 个人仓库，作为过程性加分依据。
3. **可署名责任底线**：
   严禁全盘使用 AI 代写文本作业。凡发现未经验证的 AI 幻觉编造、虚假数据或伪造访谈记录，该项成绩一律记为零分。
