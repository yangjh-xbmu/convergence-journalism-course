> **版本**：v4.0 三层架构与多方案规范  
> **依据**：开源 `design-system` 技能规范（三层 Token 架构）、W3C 中文排版需求（`w3c/clreq`）、古籍形态学与现代学术出版物美学。

## 〇、 三层 Token 架构 (Three-Layer Token Architecture)

依照 `design-system` 技能规范，设计系统建立三层不可混淆的解耦结构：

```text
Layer 1: Primitive Tokens (原始物理常量：色相阶梯、字阶、间距基数)
              ↓
Layer 2: Semantic Tokens (语义角色别名：纸张层级、墨色梯度、信号强调)
              ↓
Layer 3: Component Tokens (组件器件绑定：报头双线、条目序号、工单红框)
```

### 1. Primitive Tokens (物理原子)
- **色阶**：
  - 宣纸中性色阶：`#FAF6ED` (01), `#F6F2EC` (02), `#F2ECE0` (03), `#EAE1D2` (04), `#DDD5C5` (05)
  - 端砚墨石阶梯：`#141312` (90), `#1A1918` (80), `#262421` (70), `#5E584F` (50), `#8E8679` (30)
  - 传统矿物色相：朱砂 `#A82824` / `#9B2C1F`，霁蓝 `#1A3A68` / `#27445C`，竹青 `#2A5936`，秋香金 `#9E782F`
- **空间模数**：4px 基础网格（`4px`, `8px`, `12px`, `16px`, `24px`, `32px`, `48px`, `64px`, `96px`）
- **字阶比例**：1.25 (Major Third) 阶梯，基础正文下限 `17px` (1.0625rem)。

### 2. Semantic Tokens (语义映射)
- `--paper-base`: 当前主题的主视网膜纸张底色
- `--paper-elevated`: 抬高层（高光条目、引语块）
- `--ink-title`: 标题焦墨色 (对比度 > 15:1)
- `--ink-body`: 正文松烟墨色 (对比度 > 7:1)
- `--ink-caption`: 图注与辅助宿墨色 (对比度 > 4.5:1)
- `--rule-hairline`: 1px 经典发丝细线
- `--accent-seal`: 核心章节与可署名责任指示色（朱砂）

### 3. Component Tokens (器件专属)
- `--masthead-rule`: 刊头文武边与双线规制
- `--entry-marker`: 章节宋体大号序号颜色与字重
- `--status-badge-active`: 本周主讲状态药丸指示条

## 二、 现代高校教材文案体例规范

三套方案统一采用现代高校专业教材标准体例：
- 标题一律采用**主张式观点陈述**（如“受众雇佣价值与可署名责任”而非“道”）。
- 教学目标一律采用**布鲁姆可测动词**（识别、解构、建构、评估、设计）。
- 彻底剔除仿古装饰词汇，保持语言清晰、直接、专业。
